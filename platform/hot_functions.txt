# frank-ecat — the eCat3 functions that run from SRAM (tools/hot_sections.py)
#
# One demangled name a line, without the argument list; every overload and
# every clone (.constprop, .isra) of it is taken. Inline functions (next_byte,
# find_page) come with the functions they are inlined into. From the sampling profiler
# (~C prof~ on the console): what the emulation loop spends its time in.
# Flash goes through the 16 KB XIP cache, shared with PSRAM, and a miss is a
# QSPI transfer, so a hot function in flash costs more than its instructions.

# A line "@ family ..." scopes the entries after it to those firmwares
# (CMakeLists.txt: ecat_add_firmware's name; "@ all" for every one): SRAM is
# short, and a family that never runs a function should not carry it there.
